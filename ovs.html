OVS – Order Verification System

Process Training Document

Is page par OVS campaign ka introduction, sub-campaigns, required tools, complete working process aur Order ID / Sub Order ID ka difference diya gaya hai.

1. Introduction to OVS

OVS ka full form Order Verification System hai.

OVS ek verification campaign hai, jisme customer ke orders ko verify kiya jaata hai.

Is campaign mein unhi orders se related calls aati hain jo OVS ke four sub-campaigns ke under fall karte hain.

Main Objective: Customer ke order ko verify karna aur customer ke concern ke according appropriate ticket tagging aur disposition complete karna.

2. OVS – Sub-Campaigns

OVS ke under total 4 sub-campaigns hote hain:

S.No. Sub-Campaign Purpose
1 Address Verification Customer ke delivery address ko verify karna.
2 Duplicate Duplicate orders ko verify karna.
3 Bulk Multiple / bulk orders ko verify karna.
4 Seller RTO High High RTO-related orders ko verify karna.
Important: OVS campaign mein sirf in four sub-campaigns se related scenarios ki calls receive hoti hain.

3. Tools / Panels Used in OVS

OVS campaign mein total 3 tools/panels use hote hain.

3.1 Ozonetel – Calling Tool

Main Purpose: Calling Management

Ozonetel ek calling tool hai jahan agent ke paas campaign-related calls land hoti hain.

Ozonetel ke functions:

  • Incoming call receive karna.
  • Customer ki Order ID receive karna.
  • Customer ki Sub Order ID receive karna.
  • Call kis campaign aur sub-campaign ki hai, identify karna.
  • Call ko Hold par rakhna.
  • Call ko Disconnect karna.
Important: Ozonetel se agent ko Order ID, Sub Order ID aur Campaign Name ki information milti hai.

3.2 OVS Panel – Order Verification Tool

Main Purpose: Order Verification

OVS panel ka use customer ke order aur product ki details check karne aur order verify karne ke liye hota hai.

OVS Panel ka working process:

  1. Sabse pehle Ozonetel se customer ki Order ID copy karni hai.
  2. OVS panel open karna hai.
  3. Copied Order ID ko OVS panel mein enter karna hai.
  4. Search karne ke baad customer ke order ki details receive hongi.
  5. Product details ko check karna hai.
  6. OVS campaign ke according order verification complete karna hai.
Important: OVS panel mein Order ID ka use kiya jaata hai.

3.3 Kapture Panel – Ticketing & Tagging Tool

Main Purpose: Product Information, Ticket Tagging & Disposition

Kapture ek ticketing tool hai jisme product se related detailed information available hoti hai.

Kapture Panel ke functions:

  • Product ki detailed information check karna.
  • Customer ke concern ke according appropriate tagging karna.
  • Correct ticket category select karna.
  • Customer ke scenario ke according ticket tag karna.
  • Appropriate disposition select karna.
  • Ticket ko dispose karna.
Important: Kapture panel mein Sub Order ID ka use kiya jaata hai.

4. OVS Campaign – Complete Working Process

OVS campaign mein agent ko following sequence follow karna hota hai:

Step 1 – Call Land on Ozonetel Agent ke paas OVS campaign ki call land hogi. Agent campaign name, Order ID aur Sub Order ID identify karega.
Step 2 – Copy Order ID Ozonetel se customer ki Order ID copy karni hai.
Step 3 – Open OVS Panel OVS panel mein copied Order ID enter karke search karna hai.
Step 4 – Verify Order Customer ke product ki details check karke applicable OVS sub-campaign ke according order verify karna hai.
Step 5 – Open Kapture Panel Kapture panel open karke Ozonetel se customer ki Sub Order ID enter karni hai.
Step 6 – Concern Tagging Customer ke actual concern aur scenario ke according appropriate tagging select karni hai.
Step 7 – Ticket Disposition Correct disposition select karke ticket ko dispose karna hai.
Process Complete

5. Important Difference – Order ID vs Sub Order ID

Ye OVS campaign ka sabse important point hai.

Tool / Panel ID Required Purpose
Ozonetel Order ID & Sub Order ID Call aur order identification
OVS Order ID Order verification
Kapture Sub Order ID Product information, tagging & ticket disposal
Yaad rakhein: OVS panel mein Order ID aur Kapture panel mein Sub Order ID use hoti hai.
