Address Correction

1. Campaign Overview

OVERVIEW

Address Correction campaign mein humein un customers (CX) ki calls receive hoti hain jinke order ka delivery address incomplete ya incorrect hota hai.

Hamari responsibility hoti hai customer se correct address lena aur Kapture mein proper tagging aur details update karna.

Core responsibility: Customer se complete aur corrected address lena, phir Kapture mein required details update karna.

2. Step-by-Step Process

6 STEPS
1
Call Receive Karna

Jab Ozonetel mein Address Correction campaign ki call land hoti hai, customer ki concern handle karein.

2
Suborder ID Copy Karna

Sabse pehle customer ka Suborder ID copy karein.

3
Kapture Open Karna

Kapture mein Suborder ID paste karke customer ka order search karein.

4
Order Tagging

Order ko tag karein aur correct folder select karein.

5
Disposition Select Karna

Disposition mein Closed select karein.

6
Details Update Karna

First box mein Suborder ID aur second box mein customer ka complete corrected address enter karein.

3. Kapture Tagging

4. Details Update in Kapture

2 BOXES

Tagging aur disposition ke baad last mein do boxes milte hain:

1
First Box

Ismein customer ka Suborder ID enter karna hai.

2
Second Box

Ismein customer ka complete and corrected address enter karna hai.

5. Address Format Helper

INTERACTIVE TOOL

Customer se address lete time neeche diya gaya format follow karein. Details fill karke corrected address prepare aur copy kar sakte hain.

6. Important Note – Wrong Pincode Case

IMPORTANT
Wrong Pincode Case:
Agar kisi bhi case mein customer ka Pincode incorrect hai, toh customer ko khud se order replace karne ke liye redirect karna hai.
