NPR – Non-Pickup Report

NPR campaign mein un customers ki calls receive hoti hain jinka return pickup fail ho chuka hota hai. Jab Ozonetel mein campaign name NPR show hota hai, toh customer ki query Return Pickup Failed se related hoti hai.

Return Pickup | Ozonetel + Kapture

1. Campaign Overview

OVERVIEW

NPR stands for Non-Pickup Report.

Is campaign mein humein un customers ki calls receive hoti hain jinka return pickup fail ho chuka hota hai.

Campaign Identification: Jab Ozonetel mein call land hoti hai aur campaign name NPR show hota hai, toh samajhna hai ki customer ki query Return Pickup Failed se related hai.

Tools Used:

1. Ozonetel 2. Kapture

2. Call Handling Process

3 MAIN STEPS
1

5. Special Case – Already Picked Up But Status Showing Failed

SPECIAL CASE

Agar customer ka product already pickup ho chuka hai, lekin system mein Pickup Failed show ho raha hai, toh sabse pehle customer ka state check karna mandatory hai.

Rajasthan Customer

Customer ko guide karna hai ki woh apne Logistics Partner se coordinate karein.

Other State Customers

Rajasthan ke alawa kisi bhi other state ke customer ko 72 hours wait karne ke liye guide karna hai.

Team ki taraf se update provide kar diya jayega.

9. Return Creation – Allowed / Denied

CHECK BEFORE ACTION

Jab bhi hum ticket par return create karne ke liye click karte hain, toh screen ke bottom side se ek notification / pop-up aata hai.

Usmein do options show hote hain:

ALLOWED (A)

Agar return creation allowed hai, toh return create karna hai.

DENIED (D)

Agar return creation denied hai, toh return create nahi karna hai.

Mandatory: Return create karne se pehle Allowed / Denied status check karna compulsory hai.

10. Return Reattempt Timeline

IMPORTANT

Return pickup ke cases mein timeline depend karti hai ki hum existing return reason se pickup reattempt kar rahe hain ya new ticket create karke return bana rahe hain.

CASE 1: Same Return Reason

No New Ticket

Agar product ka return same reason se dobara create / reattempt kar rahe hain aur koi new ticket raise nahi kar rahe hain, toh customer ko 2–3 days ki timeline deni hai.

"Your return pickup will be reattempted within 2–3 days."

CASE 2: New Ticket Creation

Different Product / Wrong Reason

Agar customer ko different product receive hua hai ya existing return incorrect reason se create hua hai, toh new ticket create karna hai.

New ticket ke through correct reason select karke return create karna hai.

"We will try our best to get your product picked up within 24 hours."

11. Kapture Folder Selection and Disposition

TAGGING

Jab new ticket create karte hain ya return-related concern handle karte hain, toh Kapture mein correct folder selection karna important hai.

Post Delivery › I Want to Return / Replace › CX Issue › Relevant CX Issue

Customer ki actual concern aur RPU details ke according correct reason select karna hai.

Other Reason

Customer ki concern ke according applicable CX Issue select karein.

Smart Check Failure

Agar Smart Check Failure hai, toh uska relevant reason select karna hai.

Kapture Disposition: Awaiting Pickup

12. Important Points

QUICK REVISION
  • NPR campaign means Return Pickup Failed.
  • Always check RPU details before proceeding.
  • Pickup failure reason verify karna mandatory hai.
  • Smart Check Failure details aur images check karni hain.
  • Already Picked Up cases mein customer ka state check karna compulsory hai.
  • Rajasthan customers ko Logistics Partner se coordinate karne ke liye guide karna hai.
  • Other state customers ko 72 hours wait karne ke liye guide karna hai.
  • Address aur Pincode correction possible hai during return pickup creation.
  • Return create karne se pehle Allowed / Denied status verify karna hai.
  • Same return reason without a new ticket: 2–3 days reattempt timeline.
  • Different product / incorrect return reason with a new ticket: 24 hours best-effort pickup timeline.
  • Correct Kapture folder and Pickup reason select karna mandatory hai.
  • Kapture Disposition: Awaiting Pickup.
