OVS - Bulk Campaign

Sub-Campaign Training Document

1. Introduction to Bulk Campaign

Bulk OVS, Order Verification System ka ek sub-campaign hai.

Iska main purpose multiple / bulk orders ko verify karna hai.

Main Purpose: Multiple / bulk orders ko verify karna.

2. Tools / Panels Required

Ozonetel - Calling Tool

  • Incoming call receive karna.
  • Order ID aur Sub Order ID identify karna.
  • Campaign aur sub-campaign identify karna.
  • Call ko Hold ya Disconnect karna.

OVS Panel - Order Verification

  • Ozonetel se Order ID copy karna.
  • OVS panel mein Order ID enter karna.
  • Order details aur product details check karna.
  • Applicable campaign ke according verification complete karna.

Kapture - Ticketing & Tagging Tool

  • Sub Order ID enter karna.
  • Product information check karna.
  • Customer concern ke according tagging karna.
  • Appropriate disposition select karna.
  • Ticket dispose karna.

3. Bulk Campaign - Working Process

  1. Ozonetel par incoming call receive karein.
  2. Campaign name, Order ID aur Sub Order ID identify karein.
  3. Order ID copy karein.
  4. OVS panel open karke Order ID search karein.
  5. Order aur product details check karein.
  6. Bulk campaign ke according order verify karein.
  7. Kapture mein Sub Order ID enter karein.
  8. Customer concern ke according ticket tagging karein.
  9. Correct disposition select karke ticket dispose karein.

4. Important ID Information

OVS Panel: Order ID

Kapture: Sub Order ID
